# 🎧 Call Center Simulator

لعبة محاكاة بسيطة لتدريب موظف خدمة العملاء على استقبال المكالمات واختيار الرد المناسب.

## النسخة الأولى
- Incoming calls
- Customer scenarios
- Multiple response choices
- Quality Score
- CSAT
- AHT
- Responsive design للموبايل والكمبيوتر

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## الخطط القادمة
- مستويات Agent / Senior / Team Leader
- نظام XP وLevels
- مكالمات أكثر واقعية
- مؤقت وضغط وقت
- نظام راتب وBonus
- سجل أداء يومي
- أصوات Incoming Call
- لوحة إحصائيات
